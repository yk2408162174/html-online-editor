# 网页在线编辑器

基于 [轻页 AirPage](https://github.com/quqxui/air-html-editor) 增强的**本地 HTML 可视化编辑器**。

用 Chrome / Edge 打开 [`editor.html`](editor.html)（需与 [`wechat-clean.js`](wechat-clean.js) 同目录）。在点选 / 拖拽 / 写回之外，提供 **WPS 式文字排版**、**媒体插入**，以及 **微信文章清理**。

## 快速开始

1. 打开 `editor.html`
2. 打开或拖入本地 HTML；微信 SingleFile 导出可先点顶部「清理微信」
3. 用「组件 / 文字」模式与「开始 / 插入」功能区编辑；`Ctrl+S` 保存 HTML，`Ctrl+Shift+S` 另存为多格式

打开或新建多个 HTML 时，画布上方会出现**标签栏**，可同时编辑、切换、关闭（有未保存更改会提示）。`+` 或「新建」再开一个空白页；打开文件支持多选。

## 文档复制粘贴

功能区 **文档** 页：

1. 打开源 HTML → **复制正文**（或复制选中 / 整页）
2. **新建空白** 或打开目标 HTML
3. **粘贴内容…** → 追加文末 / 插入选中后 / 替换正文 / 粘贴到新文档  
   也可 **从文件导入** 或读系统剪贴板

## 保存 / 导出格式

| 格式 | 说明 |
|------|------|
| **HTML** | 完整网页（默认保存 / 可再次编辑） |
| **Markdown** | 标题、列表、链接、图片等 |
| **纯文本** | 仅正文文字 |
| **PDF** | 打开打印对话框 → 另存为 PDF |

点保存旁的 **▾** 选择格式。

顶部 **清理微信** 按钮（浏览器内，无需 Python）：

| 方式 | 说明 |
|------|------|
| 清理当前文档 | 对已打开的 HTML 去 chrome、内联样式 |
| 选择文章文件夹并清理 | 写回 `index.html`、备份 `.bak`、删无用图与 css/partials（需 Chrome/Edge 授权文件夹） |
| 打开 HTML 文件并清理 | 选单个导出文件，清理后载入编辑器 |

可选保留：原创/作者/时间、底栏、合集导航。

命令行等价脚本（需 `pip install beautifulsoup4 lxml`）：

```bash
py scripts/clean.py 路径/到/文章文件夹
```

## 编辑模式

顶部 **组件 / 文字** 开关（`Tab` 也可切换）：

- **组件**：点选、拖拽换位、缩放手柄、父级/复制/删除
- **文字**：点击落光标或新建段落，排版与插入媒体
- **浏览**：放行页面自身点击

组件模式下双击文字块会自动切到文字模式。

## 功能一览

### 开始（文字 / 段落）

- 标题样式、字体字号颜色高亮
- 加粗 / 斜体 / 下划线 / 删除线 / 上下标
- 对齐、行距、列表、缩进、链接、清除格式

### 插入（媒体 / 内容）

- 本地图片 / 视频 / 音频（data URL，建议 &lt; 12MB）
- 媒体 URL、段落、分隔线、表格、代码块

### 组件编辑

- 点选、拖拽换位、缩放、撤销重做、面包屑
- File System Access API 写回（Chrome / Edge）

## 目录

```
editor.html           # 主界面

scripts/clean.py      # 同逻辑命令行版
airpage-original.html # 上游原版备份
README.md
```
